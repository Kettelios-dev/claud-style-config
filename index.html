Arborescence des pages

Clique une page pour l'afficher. → la range sous la page du dessus, ← la remonte au premier niveau.

Sections

Glisse les sections pour changer l'ordre. Clique une section pour la cibler avec une directive.

L'arborescence sert à tester le style sur plusieurs pages. Par défaut elle ne part pas dans le brief : ton prompt principal décrit la structure.

Écris une directive dans la barre sous l'aperçu. Elle modifie les réglages, l'ordre des sections ou ajoute un petit CSS ciblé. Toutes les directives partent aussi dans le brief.

Une directive est classée « contenu » si elle cible une section ou change l'ordre des sections, sinon « style ».
